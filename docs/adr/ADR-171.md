# ADR-171: Remove underline from tree item text

- **Issue:** [#171](https://github.com/jasonmotylinski/hierarchical-backlinks/issues/171)
- **Status:** Accepted
- **Date:** 2026-09-11
- **Reporter:** AE-SAY-WAY

## Context

Obsidian's default CSS applies `text-decoration: underline` to `.tree-item-inner` elements. When the hierarchical backlinks plugin renders folder and note names in the tree, they inherit this underline styling. Users found it visually distracting, especially when hovering or interacting with folder rows.

The plugin's `styles.css` did not override this default, so the underline appeared on all tree item text.

## Decision

Add `text-decoration: none` to `.tree-item-inner` within the plugin's scoped CSS selector. This strips the underline unconditionally — no setting needed, as the underline serves no functional purpose in this context.

## Consequences

- Clean, minimal visual appearance for all tree rows
- No user-facing setting required
- One CSS rule in `styles.css`, scoped to the plugin's container to avoid affecting other Obsidian views
